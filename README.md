# Portafolio Profesional — Kevin Holguín Orrego

Portafolio web One-Page desarrollado aplicando las herramientas y buenas prácticas del bootcamp **Java Full Stack de Generation Colombia** y cumpliendo con la lista de verificación oficial del portafolio.

## Stack y Arquitectura Aplicada

- **HTML5 Semántico & Accesibilidad (WAI-ARIA):** Estructura clara en primera persona, jerarquía tipográfica y soporte de lectura accesible.
- **CSS3 Moderno (`:root`):** Variables centralizadas para la paleta **Monocromo Carbono (`#0E0E10`) & Lima Ácida (`#BEF264`)**, combinación tipográfica editorial (**Syne** + **Playfair Display**) y cortina animada de bienvenida (`KHO.`).
- **Bootstrap 5.3:** Sistema de rejillas responsivas de 12 columnas y modal interactivo para inspección técnica de cada proyecto.
- **JavaScript Modular ES6+ (`import`/`export`):**
  - `js/data.js`: Repositorio estructurado de proyectos colaborativos, experiencia, educación y habilidades.
  - `js/dom.js`: Renderizado dinámico del contenido y actualización del modal técnico.
  - `js/events.js`: Gestión de eventos, apertura de casos de estudio, `localStorage` y Clipboard API.
  - `js/main.js`: Orquestación principal y `IntersectionObserver` para animaciones al hacer scroll.

## Instalación y Uso Local

1. Guarda la imagen de fondo aprobada en `assets/img/hero-bg.jpg`.
2. Abre la carpeta en VS Code y ejecuta con **Live Server** (requerido para que los módulos ES6 `type="module"` carguen correctamente por HTTP).
3. Sube el contenido a tu repositorio `kholguin-dev.github.io` para publicarlo en **GitHub Pages**.
